Программа ascue viewer предназначена для просмотра данных из ТМК "Компас". Для просмотра доступны :
 - показания счетчиков; 
 - просмотр энергии (расхода) по дням;
 - просмотр суточного потребления РП за период (по дням и получасам); 
 - просмотр суточного потребления по счетчикам (присоединениям);
 - просмотр небаланса РП за период; 
 - просмотр токов и напряжений (необходимо выбрать галочку "Изм");
 - просмотр профилей мощности;
 - просмотр данных из энергомеры (на данное время только РП-76);
 - отображение графиков.
1. Для просмотра показаний необходимо:
   1.1 выбрать РП из списка;
   1.2 выбрать присоединение (либо все, указав галочку напротив "пок");
   1.3 выбрать период (дату), а так же время (можно указать конкретную дату (время), 
     указав одно и то же в разных полях);
   1.4 нажать на кнопку "Результат".
   * Если нужно просмотреть энергию (расход), необходимо выбрать галочку "по дням"
     и нажать на кнопку "Результат".
2. Для просмотра небаланса РП повторить пункты 1.1, 1.3 и нажать в поле отображения таблиц на правую кнопку мыши. В выпадающем меню выбрать "Небаланс".
3. Для просмотра суточного потребления за период, необходимо повторить пункты 1.1, 1.3 и нажать в поле отображения таблиц на правую кнопку мыши. В выпадающем меню выбрать "Суточное потребление".
4. Для просмотра суточного потребления за каждый получас, необходимо:
   4.1 повторить пункт 1.1;
   4.2 На панели "небаланс получасов за сутки" выбрать необходимую дату и нажать кнопку "Небаланс"      (данные за всю РП), либо "Присоединения" (данные по присоединениям). Также можно выбрать время из    выпадающего списка, если Вы хотите увидеть днные на конкретное время по всем присоединениям и    конкретное присоединение.
5. При просмотре графика можно менять его вид. Если это график небаланса, то возможен дополнительный просмотр при выборе "%" из выпадающего списка, для просмотра небаланса в процентах.
6. Для печати или сохранения данных из главной формы, необходимо в меню "Файл" выбрать нужное действие.
7. Для печати графиков необходимо нажать правой кнопкой мыши на графике и в меню выбрать печать.
8. Для просмотра данных из энергомеры необходима выбрать галочку "Энергомера"
9. Для Просмотра всех недостоверных данных на выбранное вами время следует выбрать "файл" далее "Отчет неответ".


ВАЖНО!

Для того, чтобы просматривать Небаланс РП за период либо Суточное потребление, необходимо выбрать РП
и в настройках галочками отобразить, что является вводами, а что присоединениями. А также ввести коэффициенты
трансформации.Данные вводятся всего один раз, и они влияют на получение сут. периода и небаланса. 
Поэтому эти данные нужно вводить внимательным образом и только ПО РП СВОЕГО УЧАСТКА (южный, западный и т.д.)
Если данные уже введены, то вводить заново их не нужно. Также можно ввести номера счетчиков.
Заметим, что данные могут вводить только администраторы (согласно служебной записке). Пользователям доступен только просмотр.
Если Вы не уверены в правильности ввода, позвоните по тел.
